# Reel types (every Kitty Gang reel is a live experiment)

8 of the first 10 reels were the same type (living-room sitcom), so we learned nothing about what else works.
Each reel now picks a TYPE that is not among the last 4 reels' `experiment.type`, names one thing it tests, and
the Monday LEARNINGS update compares types by skip rate, watched %, shares and saves. Once a type clearly wins,
use it at most every 2nd reel and keep testing the rest. Add new types at the bottom when you invent one.

| type | what it is | kits that carry it |
|---|---|---|
| sitcom | a living-room scene with a want, 3 escalations, twist, button (the old default) | scene |
| group-chat | the story told as the gang's WhatsApp group: messages, voice-note lines, a last message twist | phone (+ scene cutaways) |
| types-of | "Har kitty mein 4 type ki aunty": one member each, a chip with the type, quick cuts | scene / solo, chip |
| pov | "POV: aap host ho aur 6:55 ho gaye", the camera is the viewer, members talk to camera | solo / scene, camera "push" |
| expectation-reality | split screen or back-to-back: the plan vs what happened | duo, scene |
| countdown | "3 cheezein jo har kitty mein hoti hain" numbered chips, a twist on number 1 | scene, chip |
| photo-attempts | the group photo that never works: attempts 1, 2, 9 | camera |
| door-arrivals | who arrives how (late, overdressed, with a plus one), each entry a joke | door / scene entrance |
| story-time | one member tells a 15 s story, cut to the moment | solo then scene |
| quiz | viewers guess (whose kitty? which number? who said it?), reveal after 3-2-1, "comment karo" | scene, card, chip |
| musical | lines on a beat, chorus `ALL` refrain, almost a song | room / scene, pace 26 |
| meme-format | a known Indian reel pattern played by the gang (no copying, the pattern only) | any |
| map-journey | the trip to the kitty: traffic, wrong flat, 3 stops | map + door |

`experiment` in the draft: `{ "type": "group-chat", "hook": "what the first 2 s do", "variable": "the one thing tested", "hypothesis": "what we expect, with a number" }`
